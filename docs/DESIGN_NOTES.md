# GEAR BASE MVP 設計メモ

このドキュメントは、GEAR BASE MVP開発における主要な設計判断と技術選定の理由を記録します。

---

## 1. 現在採用している構成

GEAR BASEは、以下の技術スタックとアーキテクチャで構築されています。

*   **フレームワーク:** Flutter (iOS/Android/Web対応)
*   **言語:** Dart
*   **状態管理:** Riverpod
*   **データ永続化:** SQLite (sqflite / driftパッケージを使用)
*   **データモデル:** アプリケーションローカルでの以下のデータモデルを採用しています。

    ### 1.1. ユーザー (User)
    *   `id`: String (ユニークID)
    *   `name`: String
    *   `email`: String (任意)
    *   `created_at`: Timestamp

    ### 1.2. キャンプギア (CampGear)
    *   `id`: String (ユニークID)
    *   `user_id`: String (FK to User.id)
    *   `name`: String
    *   `category`: String (テント、タープ、寝袋など)
    *   `description`: String (任意)
    *   `image_path`: String (ローカルファイルパス、任意)
    *   `quantity`: Integer
    *   `purchase_date`: Date (任意)
    *   `price`: Double (任意)
    *   `notes`: String (任意)
    *   `created_at`: Timestamp
    *   `updated_at`: Timestamp

## 2. 主要機能 (MVPスコープ)

*   **ユーザー管理:** ローカルでのユーザー作成、管理。
*   **ギアの登録・編集:** キャンプギア情報の登録、編集、削除。
*   **ギアの一覧表示:** 登録されたキャンプギアのリスト表示（カテゴリ別フィルター機能も検討）。
*   **ギアの詳細表示:** 個別ギアの詳細情報表示。
*   **近くのお店検索:** ユーザーの現在地周辺のキャンプ用品店を検索し、リスト表示する。（今回のMVP目標）

## 3. 将来検討事項

MVPの達成後、以下の項目を検討します。

*   **クラウド同期:** ローカルデータのクラウドサービス（Firebase/Supabaseなど）との同期機能の導入。
*   **ユーザー認証:** クラウドサービスを利用した認証機能の強化（例: Google/Appleサインイン）。
*   **画像管理:** 画像ファイルのアップロードと管理（ローカルストレージからクラウドストレージへの移行）。
*   **AI連携:** アプリケーション内でのAIを活用した機能（例: ギアの自動分類、推奨、使用状況分析など）。
*   より高度な検索・フィルタリング機能。
*   国際化対応の計画。
*   CI/CDパイプラインの構築。
*   テスト戦略の詳細化。
