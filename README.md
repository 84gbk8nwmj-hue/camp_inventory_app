# GEAR BASE

GEAR BASE is a Flutter application for managing camping gear.

## Features

- Gear management
- Categories
- Packing sets
- Nearby camping store search
- Theme customization
- Import / Export (JSON / ZIP)

## Tech Stack

- Flutter
- Riverpod
- SQLite
- Geolocator
- Overpass API
